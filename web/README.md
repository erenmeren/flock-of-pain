# Flock of Pain web

Next.js dashboard for the Flock of Pain API. Setup, environment (`NEXT_PUBLIC_API_URL`) and a page tour live in the root [README](../README.md#web), "Web" section.

- `npm run dev`: development server on http://localhost:3000
- `npm run lint`: ESLint
- `npm test`: assert-based checks of the pure Company/Scenario logic (`scripts/check.ts`)
